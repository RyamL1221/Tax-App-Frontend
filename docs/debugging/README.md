# Debugging Documentation

## Purpose

This folder contains documentation related to debugging sessions, investigations, root cause analyses, and fix verifications. These documents capture the process of identifying, investigating, and resolving issues in the application.

## What Goes Here

### Debug Session Notes
Documents that capture debugging sessions and investigations:
- Debug session notes
- Investigation processes
- Troubleshooting steps
- Debug findings

**Naming Convention:** `debug-{issue-description}.md`

**Examples:**
- `debug-jwt-token-persistence.md`
- `debug-token-check.md`

### Investigation Results
Documents that summarize investigation outcomes:
- Investigation results
- Analysis findings
- Issue identification
- Problem characterization

**Naming Convention:** `investigation-{description}.md`

**Examples:**
- `investigation-results.md`

### Root Cause Analysis
Documents that identify root causes of issues:
- Root cause analysis
- Causal chain documentation
- System behavior analysis
- Issue origin identification

**Naming Convention:** `root-cause-{description}.md`

**Examples:**
- `root-cause-analysis.md`

### Fix Verification
Documents that verify fixes and solutions:
- Fix verification reports
- Solution validation
- Regression testing after fixes
- Fix effectiveness documentation

**Naming Convention:** `fix-{description}.md`

**Examples:**
- `fix-verification.md`

### Debugging Instructions
General debugging guides and procedures:
- Debugging procedures
- Troubleshooting guides
- Debug tool usage
- Next steps for ongoing issues

**Naming Convention:** `debugging-{description}.md`

**Examples:**
- `debugging-instructions.md`
- `debugging-next-steps.md`

## When to Add Documents Here

Add documentation to this folder when:
- Conducting a debugging session
- Investigating an issue or bug
- Performing root cause analysis
- Verifying a fix
- Creating debugging procedures
- Documenting troubleshooting steps

## File Naming Conventions

- Use lowercase with hyphens
- Include issue or feature context
- Be descriptive about the debugging activity
- Use `.md` extension for markdown files

- **Implementation Docs**: `../implementation/` for task summaries

- **Feature Docs**: `../features/` for feature-specific fixes
